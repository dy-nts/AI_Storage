# ALLDATASHEET

- URL: [ALLDATASHEET 한국어](https://www.alldatasheet.co.kr/)
- 분류: 전자부품 데이터시트 검색 서비스, 제조사 공식 사이트가 아닌 보조 검색처
- 확인 범위: 홈페이지의 부품명 입력 검색 및 제조사별 검색 링크
- 등록일: 2026-10-26

## 활용 방법

1. 전체 부품명으로 검색합니다. 예: TLE9877QXA40, TLE9879QXA40.
2. 검색 결과의 제조사와 품번 접미사를 확인합니다.
3. 문서 표지의 리비전과 발행일을 확인합니다.
4. 제조사 공식 데이터시트 및 해당 silicon step의 Errata와 대조합니다.
5. 검토한 페이지·절, 비교 결과와 확인일을 기록합니다.

이는 권장 검토 절차입니다. 예시 품번의 검색 결과나 개별 PDF는 이번 등록에서 확인하지 않았습니다.

## 출처 우선순위

- 1순위: 제조사 공식 데이터시트, User Manual, Errata
- 2순위: ALLDATASHEET에서 발견한 문서와 검색 결과

공식 원문과 내용이 다르면 해당 제품에 적용되는 공식 문서를 우선하고 차이를 기록합니다. 공식본 대조 전에는 최신판 또는 검증 완료로 표시하지 않습니다. 홈페이지 확인만으로 개별 데이터시트의 정확성을 보증하지 않습니다.

## 현재 반영 범위

검색처와 사용 기준을 추가했습니다. 자동 크롤링, 정기 수집, 개별 PDF 다운로드는 설정하지 않았습니다. 수집한 문서가 생기면 문서별 출처 ID를 따로 부여합니다.
